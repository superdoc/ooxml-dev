# ooxml.dev

## What it is

ooxml.dev is an interactive OOXML reference and MCP server for developers building document tools.

## What it owns

- Clear explanations of the published OOXML specifications and schemas.
- Evidence-backed notes about how Word and other applications behave.
- Small, working XML examples with live document previews.
- Search and structural lookup tools for OOXML implementers.

## What it does not own

- Implementing or supporting a document editor.
- General DOCX editing, conversion, or end-user workflows.
- Behavior claims that are not supported by a source or a verified example.

## Current direction

- Write for implementers and focus on details the specification does not make clear.
- Keep specification rules separate from application-specific behavior.
- Keep content concise, practical, and reproducible from its sources.
